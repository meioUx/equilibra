# Equilibra

Site desenvolvido localmente com Vite, HTML, CSS e JavaScript.

## Desenvolvimento

```sh
npm install
npm run dev
```

Abra o endereço local mostrado no terminal. As alterações aparecem automaticamente no navegador.

No PowerShell com execução de scripts bloqueada, use `npm.cmd install` e `npm.cmd run dev`.

## Build

```sh
npm run build
npm run preview
```

O build é gerado em `dist/`.

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `src/style.css`: identidade visual e layout responsivo.
- `src/main.js`: interações e seleção das telas do app.
- `public/assets/`: marca e capturas originais do aplicativo.
- `material/`: material de referência extraído do ZIP.

O botão da Google Play abre uma busca pelo aplicativo. Substitua pelo link oficial quando disponível.
